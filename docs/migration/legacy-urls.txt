# (`/tags/#meta`, `/categories/#consulting`). Hash fragments are never sent
# to the server, so these effectively land on `/tags/` and `/categories/`
# pages (lists). On the new site, /tags/<tag>/ pages exist, but these are a
# different URL shape — redirect the index pages to a sane destination.

/tags/                                            REDIRECT  /posts/
                                                  # legacy tags index → posts archive (no canonical /tags/ index in new site)
/categories/                                      REDIRECT  /posts/
