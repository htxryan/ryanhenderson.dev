Penmoss stores notes as plain markdown files in a private git repository you
choose, synced by git. Claude, Codex, OpenCode or any MCP agent can read and
edit them through MCP or a CLI, and every edit shows who made it and can be
undone.

Comment on a note and the agent replies in the thread. Search by words or by
meaning, work offline, and keep both sides of any offline edits when they
merge. No server, account or subscription. Open source (MIT).
