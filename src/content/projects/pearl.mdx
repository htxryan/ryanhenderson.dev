Pearl is a rich web GUI for [Beads](https://github.com/steveyegge/beads), the
git-native issue tracker built for AI agents and humans working in the same
repo. It keeps Beads' append-only, file-backed model and adds a fast,
keyboard-driven interface for browsing, filtering, and editing work.

## What it is

A read-write surface for the Beads CLI: the same `bd ready` queue, the same
dependency graph, the same Dolt-backed sync — rendered for eyes and hands
instead of pipelines.

## Why it exists

Agents are great at running `bd create` and `bd close`. Humans want to scan
twenty issues at once, drag dependencies, and see the blocked graph as a
graph. Pearl is the human-facing half of a tracker that was designed for
both audiences.
