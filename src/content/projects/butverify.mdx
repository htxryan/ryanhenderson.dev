butverify is hosting designed for the loop where an AI agent ships work and a
human needs to see it instantly. The agent runs `bv push`; butverify tarballs
the directory, uploads it, and prints back a private URL the human can open.
No DNS, no buckets, no IAM, no auth code to write.

## What it is

A one-command publish surface. Sites are private by default, gated by GitHub
identity through Cloudflare Access — share by GitHub login, not by password.
Every push is a content-addressed snapshot; free sites expire in 30 days,
and the ones you care about can be pinned.

## Why it exists

Agents are great at producing output and bad at proving it. Screenshots get
lost in transcripts; "trust me, the build works" doesn't. butverify shortens
the distance from "the agent claims it works" to "here is the URL, look" to
a single shell command — designed to slot into Claude Code, Cursor, Codex
CLI, or anything else that can shell out and parse JSON.
